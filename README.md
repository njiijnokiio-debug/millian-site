# MILLIAN

Одностраничный сайт личного бренда веб-разработчика MILLIAN.

## Возможности

- адаптивная вёрстка для смартфонов, планшетов и компьютеров;
- анимации GSAP и плавная прокрутка;
- портфолио и калькулятор стоимости;
- форма заявок с отправкой в Telegram через серверную функцию Vercel;
- SEO-метаданные, Open Graph, JSON-LD, sitemap и robots.txt.

## Публикация

Проект разворачивается на Vercel. Для работы формы необходимо добавить переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в настройках проекта и выполнить повторное развёртывание.

Файл `.env.example` содержит только названия переменных. Реальные значения не должны попадать в GitHub.
