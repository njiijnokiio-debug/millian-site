TELEGRAM-ФОРМА MILLIAN

1. Публикуйте содержимое папки emilian-html как проект Vercel.
2. В настройках проекта добавьте переменные окружения:
   TELEGRAM_BOT_TOKEN — токен бота от BotFather
   TELEGRAM_CHAT_ID — ID группы с минусом в начале
3. Добавьте бота в нужную Telegram-группу и разрешите ему отправлять сообщения.
4. Выполните повторное развёртывание проекта после добавления переменных.

Важно: при открытии index.html через file:// форма не может обращаться к
серверной функции опубликованного сайта. Проверяйте отправку на размещённом сайте
или через локальный сервер Next.js из корня проекта.
